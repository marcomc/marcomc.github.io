## Um pequeno site, com uma pegada leve

Este site apresenta os serviços de desenvolvimento de software, desenvolvimento web e consultoria DevOps prestados diretamente por Marco Massari Calderone sob o nome MarcoMC. O âmbito e o orçamento são definidos para cada projeto. Para consultoria ou um orçamento: [marco@marcomc.com](mailto:marco@marcomc.com).

Não existem rastreadores publicitários, scripts de análise, formulários de contacto ou widgets de terceiros incorporados. A aparência escolhida fica guardada localmente no navegador. A opção “Sazonal” guarda a preferência por uma aparência que muda com as estações.

Os fornecedores de alojamento e rede processam dados de ligação para disponibilizar e proteger o site. Se me enviar um email, utilizo as informações fornecidas para responder e conversar sobre os serviços solicitados. Evite incluir informações sensíveis no primeiro contacto.
